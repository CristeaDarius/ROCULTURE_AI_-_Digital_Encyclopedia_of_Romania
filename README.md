# ROCULTURE_AI_-_Digital_Encyclopedia_of_Romania
Just the poster

ROCULTURE AI project aims to develop an intelligent platform for promoting and valorizing Romanian cultural heritage using advanced AI technologies. The platform focuses on digitizing, classifying, and contextualizing cultural resources - both tangible and intangible - making interactive information accessible to the public. The platform aspires to be a modern reference for preserving and transmitting cultural values.
